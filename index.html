NotepadDivColor - Características Completas

Editor de texto con colores por caracter/nota. Prueba a escribir, pulsar Enter (nueva línea), seleccionar con el ratón.

Controles Principales

Características Completas de Notepad.js

Categoría Característica / Método Descripción Ejemplo / Prueba
Constructor y Configuración
Opciones del Constructor
Constructor new Notepad(options) Crea una nueva instancia del notepad con opciones configurables
new Notepad({
  width: 600,
  height: 300
})
Configuración width, height Tamaño del contenedor en píxeles
Configuración fontSize, fontFamily Tamaño y familia de fuente
Configuración insertionMode Modo de inserción: 'letter' o 'word'
Configuración noteColorMap, colorMap Mapa de colores para caracteres/notas
Métodos de Manipulación de Texto
Inserción insertText(text) Inserta texto en la posición actual del cursor
Inserción insertTextAsWordBlocks(text, options) Inserta texto como bloques de palabras con colores
Obtención getPlainText() Devuelve el texto plano sin formato
Obtención getRichContent() Devuelve array con texto y colores
Obtención getDetailedJSON() Devuelve JSON detallado de cada caracter
Establecimiento setFromPlainText(text) Reemplaza contenido con texto plano
Establecimiento setFromRichContent(array) Reemplaza contenido con array enriquecido
Portapapeles y Selección
Portapapeles copy() Copia la selección actual al portapapeles
Portapapeles cut() Corta la selección actual
Portapapeles paste() Pega del portapapeles
Colores y Estilos
Colores setNoteColorMap(map) Establece mapa de colores para notas
Colores setNoteColor(note, color) Establece color para una nota específica
Colores setColorFunc(func) Establece función personalizada para colores
Colores setRainbowCycleMode(steps) Activa modo ciclo arcoíris
Colores recolor() Vuelve a aplicar colores según reglas actuales
Estilos setLetterPadding(y, x) Establece padding interno de las letras
Estilos setLetterMargin(margin) Establece margen entre letras
Estilos setLetterBorder(width, color) Establece borde de las letras
Estilos setLetterBorderRadius(radius) Establece radio de borde de letras
Estilos setTextColor(color) Establece color del texto
Estilos setTextColorFunc(func) Función personalizada para color de texto
Contenedor y Apariencia
Contenedor setAppBackground(color) Establece fondo de toda la aplicación
Contenedor setContainerBackground(color) Establece fondo del contenedor
Contenedor setContainerPadding(padding) Establece padding del contenedor
Contenedor setBorder(width, color, radius) Establece borde del contenedor
Contenedor setResizable(enabled) Permite redimensionar contenedor
Modo de Edición
Edición setEditable(enabled) Habilita/deshabilita edición
Edición setOverwriteMode(enabled) Activa modo sobrescritura
Edición focus() Enfoca el notepad para escribir
Exportación
Exportación exportAsImageWithP5(filename, opts) Exporta a PNG usando p5.js (preferido)
Exportación exportAsImageCanvas(filename, opts) Exporta a PNG usando Canvas (fallback)
Eventos
Eventos on(event, handler) Registra manejador de eventos
np.on('change', () => {
  console.log('Cambió')
})
Eventos 'change' Se dispara cuando cambia el contenido Ver consola al modificar
Eventos 'noteClick' Al hacer clic en una nota/caracter Ver consola al clickar letras
Eventos 'containerClick' Al hacer clic en el contenedor Ver consola al clickar fondo
Eventos 'copy', 'paste' Al copiar o pegar contenido Ver consola al copiar/pegar
Métodos Estáticos
Estático Notepad.assignRandomColors() Genera mapa de colores aleatorios
Estático Notepad.assignRainbowColors() Genera mapa de colores arcoíris
Estático Notepad.generateRainbowColors(steps) Genera array de colores arcoíris
Estático Notepad.generateRandomColors(steps) Genera array de colores aleatorios
Estático Notepad.getContrastColor(color) Devuelve color de contraste (blanco/negro)
Estático Notepad.getComplementaryColor(color) Devuelve color complementario
Estático Notepad.ALPHABET Array de letras/números por defecto
Utilidades
Utilidad setSize(width, height) Cambia tamaño del contenedor
Utilidad setFont(family, size) Cambia fuente y tamaño
Utilidad destroy() Destruye instancia y limpia eventos
Utilidad resetSequence() Reinicia índice de secuencia de colores

JSON Detallado de Contenido

Este JSON muestra la estructura detallada de cada caracter en el notepad, incluyendo colores, estilos y posición.

Consejos de uso:
  • Haz clic en los botones "Ver en consola" para ver resultados detallados en la consola del navegador (F12)
  • Usa Ctrl+C, Ctrl+X, Ctrl+V para copiar, cortar y pegar (o los botones en la tabla)
  • Haz doble clic en una letra para editar dentro de ella
  • Arrastra para seleccionar texto
  • Prueba los diferentes modos de inserción (letra vs palabra)
  • Exporta imágenes PNG con diferentes opciones de escala y fondo
